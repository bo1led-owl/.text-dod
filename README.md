# properly cooking with data-oriented design

## Структура репозитория

- `assembler.zig` - ассемблер программ
- `dod.zig` - data-oriented реализация
- `oop.zig` - "object"-oriented реализация
- `gen.go` - генератор программ на исходном языке
- `example` - пример кода на исходном языке
- `pres.pdf` - презентация к докладу
- `pres/` - исходный код и ресурсы презентации (и даже сценарий доклада)

## Команды

Полный список команд можно получить через `zig build -l`. `run-*` запускают соответствующие реализации, `assemble` позволяет собрать исходный текст в бинарный формат, `bench` запускает бенчмарк.

## Генерация исходных файлов

Параметры указываются в `gen.go`, генерация запускается через `go run gen.go`, вывод в stdout

## Запуск бенчмарка

Для бенчмарка необходим `hyperfine`.

`zig build --release=fast bench` запустит бенчмарк реализаций на программе в файле `benchmark-input`. `benchmark-input` должен содержать исходный код. Команда его автоматически соберёт и передаст реализациям

## Грамматика языка

```bnf
program := stmt*
stmt    := expr "\n"
expr    := "print" expr | op expr expr | name | number
op      := "=" | "+" | "-" | "*" | "/"
```

## Семантика языка

### Типы

Все выражения имеют тип `u64`

### Порядок исполнения

Top-level выражения исполняется последовательно. Аргументы каждой операции вычисляются до передачи, слева направо.

### Область видимости

Область видимости единственна. Все переменные, определённые где-либо *до* вычисления текущего выражения, видны в нём.

Пример:
```
= a + = b 42 b
print + = a + a 3 a
```

Записывая в привычном инфиксном синтаксисе:
```
a = (b = 42) + b
print + = a + a 3 a
```

### Операции

- `print` - печатает значение аргумента в stdin и возвращает его
- `+`, `-`, `*` - очевидный эффект
- `/` - если правый операнд не равен нулю, производит деление, иначе возвращает максимальное значение `u64`
- `=` - ожидает левым операндом идентификатор, присваивает по этому имени значение правого операнда и возвращает его. Если переменная не была определена ранее, она вводится в область видимости.
